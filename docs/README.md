# Documentation

This directory holds the repository's longer-form documentation. It starts
empty on purpose: the scaffold has nothing to document beyond what
[README.md](../README.md) (the repository map), [CONTRIBUTING.md](../CONTRIBUTING.md)
(the engineering process) and [AGENTS.md](../AGENTS.md) (the rules an agent or
contributor is held to) already say — and documentation that restates a fact
owned elsewhere is a drift risk, not a convenience.

When the first design question arrives that deserves prose of its own — the
provider abstraction, the routing model, the metering contract — it gets an
`adr/` (architecture decision record) here rather than a section in a growing
README, so every decision stays findable and citable.
